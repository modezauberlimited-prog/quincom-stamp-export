# Quincom UAE company stamp (export)

Public handoff of the EmiraBooks-generated Quincom UAE stamp.

## Files
- `quincom-uae-stamp-from-generator.svg` — vector stamp
- `quincom-uae-stamp-from-generator.png.b64` — PNG as base64 (one line)

## Decode PNG

```bash
curl -sL https://raw.githubusercontent.com/modezauberlimited-prog/quincom-stamp-export/main/quincom-uae-stamp-from-generator.png.b64 | base64 -d > quincom-uae-stamp-from-generator.png
```

Generated from EmiraBooks stamp renderer using Quincom legal data (`Quincom Ecommerce - FZCO`, LIC 47697). Not the production Supabase `stamp_url` asset.
